## Steady‑State Error for a Type‑0 System

What do we know when the system is type 0?
From the table we consulted, a type 0 system subjected to a unit‑step input exhibits a finite steady‑state error.
The corresponding error constant, \(K_p\), is obtained as the limit of the open‑loop transfer function as \(s \to 0\).

## Calculating \(K_p\)

We compute \(K_p = \displaystyle \lim_{s \to 0} G(s)H(s) = \frac{500}{400} = \frac{5}{4}\).
Thus the static error constant \(K_p\) equals \(1.25\).

## Computing the Static Error

The static error for a unit‑step input is

\[
e_{ss} = \frac{1}{1 + K_p} = \frac{1}{1 + \frac{5}{4}} = \frac{1}{\frac{9}{4}} = \frac{4}{9} \approx 0.44 .
\]

## Interpreting the Result

The input is a unit step of magnitude 1, and the steady‑state output settles at approximately 0.56, because the error of 0.44 is subtracted from the input.
Therefore the static‑error calculation yields a negative value of –0.44 when written as “1 – 5/4”, which simply reflects that the output is lower than the input.
