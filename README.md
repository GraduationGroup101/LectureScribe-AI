# LectureScribe-AI

LectureScribe-AI is a Python project for converting lecture videos/audio into cleaned text transcripts. It downloads lecture audio from YouTube, transcribes it using faster-whisper, then cleans the transcript using a local Llama model through Ollama.

## Project Goal

The project is designed for university lectures, especially Arabic lectures that contain English technical terms. It helps produce cleaner lecture notes by:

- Downloading lecture audio from YouTube as MP3
- Transcribing Arabic lecture audio with faster-whisper
- Cleaning noisy ASR output with Llama through Ollama
- Saving both raw and cleaned transcript files

## Main Workflow

1. The user enters a YouTube lecture URL.
2. `url_to_mp3.py` downloads the video audio as an MP3 file into `downloads/`.
3. `MainCode_FasterWhisper.py` loads the faster-whisper model.
4. The MP3 is transcribed and saved into `OutputForWhisper/`.
5. `clean_with_Llama.py` sends the transcript to Ollama/Llama in chunks.
6. The cleaned transcript is saved into `OutputForOllama/`.

## Main Files

- `MainCode_FasterWhisper.py`
  - Main pipeline script.
  - Downloads audio, transcribes it, saves the raw transcript, then calls the cleaning step.

- `url_to_mp3.py`
  - Downloads YouTube audio using `yt-dlp`.
  - Converts audio to MP3 using FFmpeg.
  - Reuses existing downloaded files when possible.

- `clean_with_Llama.py`
  - Cleans the raw Whisper transcript using a local Ollama model.
  - Splits long transcripts into chunks.
  - Saves cleaned output files.

## Output Folders

- `downloads/`
  - Stores downloaded MP3 lecture audio.

- `OutputForWhisper/`
  - Stores raw transcripts generated by faster-whisper.

- `OutputForOllama/`
  - Stores cleaned transcripts generated by Llama/Ollama.

## Requirements

Install the required Python packages:

```bash
pip install -r requirements.txt
```

You also need:

- FFmpeg installed and available in PATH
- Ollama installed and running locally
- The Llama model used in `clean_with_Llama.py`
- A faster-whisper model available locally or downloadable

## File naming and caching

Downloaded MP3 files are now stored with a deterministic name based on the video ID and sanitized title, for example:

```text
downloads/<video_id>_Lecture_Title.mp3
```

If the same video is downloaded again, the script will reuse the cached MP3 file when possible.

## Ollama Model

The cleaning script currently uses:

```python
MODEL = "llama3.1:8b-instruct-q4_K_M"
```

Make sure the model is available in Ollama:

```bash
ollama pull llama3.1:8b-instruct-q4_K_M
```

Start Ollama before running the cleaner:

```bash
ollama serve
```

## Running the Full Pipeline

Run:

```bash
python MainCode_FasterWhisper.py
```

Then enter the YouTube lecture URL when prompted.

## Running the API

For a detailed explanation of the API design and workflow, read `API_WORKFLOW.md`.

The API saves job history in `jobs.json`, so completed jobs can still be listed after restarting the server. If the server restarts while a job is still running, that job is marked as failed because the background transcription thread was stopped.

Start the FastAPI server:

```bash
uvicorn api:app --host 127.0.0.1 --port 8000
```

Open the interactive API docs:

```text
http://127.0.0.1:8000/docs
```

Create a transcription job:

```bash
curl -X POST http://127.0.0.1:8000/jobs ^
  -H "Content-Type: application/json" ^
  -d "{\"youtube_url\":\"https://www.youtube.com/watch?v=dQw4w9WgXcQ\",\"clean\":true}"
```

Check job status:

```bash
curl http://127.0.0.1:8000/jobs/<job_id>
```

Read the cleaned transcript after the job completes:

```bash
curl http://127.0.0.1:8000/jobs/<job_id>/transcript
```

Read the raw Whisper transcript instead:

```bash
curl "http://127.0.0.1:8000/jobs/<job_id>/transcript?kind=raw"
```

## Running Only the Cleaning Step

If you already have a transcript file, update the `INPUT_TXT` path inside `clean_with_Llama.py`, then run:

```bash
python clean_with_Llama.py
```

## Notes

- The current transcription settings use Arabic language mode.
- The project is configured for CUDA GPU usage.
- If you do not have a CUDA GPU, change `DEVICE = "cuda"` to `DEVICE = "cpu"` in `MainCode_FasterWhisper.py`.
- Some paths, such as the FFmpeg path and local faster-whisper model path, are currently machine-specific and may need to be updated.
